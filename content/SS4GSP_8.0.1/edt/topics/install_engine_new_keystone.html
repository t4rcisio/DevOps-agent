Connecting engines to Keystone servers

Edit online

If you have an engine, you can connect it to a Keystone server for a new cloud.

Before you begin

  • You must have an engine that is configured.
  • You must have an OpenStack Keystone server.

About this task

These steps configure an engine to accept connections to a new cloud.

Procedure

  1. On the engine, open Heat configuration file.
    By default, this file is in the location /etc/heat/heat.conf .
  2. In this file, find the allowed_auth_uris property in both the auth_password and, if applicable, the ec2authtoken sections.
    This property is a comma-separated list of Keystone servers that the engine can contact.
  3. Add the complete URL to the Keystone server to each allowed_auth_uris property.
    For example, if the engine connects to clouds at cloud1.example.com and cloud2.example.com, the property might look like the following example:
    allowed_auth_uris=http://cloud1.example.com:5000/v2.0,http://cloud2.example.com:5002/v2
  4. Save and close the file.
  5. Restart the engine. 
    systemctl restart openstack-heat-engine.service
  6. Restart the Heat API. 
    systemctl start openstack-heat-api.service
