Installing and uninstalling test fixes (patches) from the server

Edit online

Test fixes are provided to correct specific issues. They are applied to the server as patches.

Before you begin

Ensure that you have the correct version of the server installed, as listed in the readme file for the test fix.

About this task

In most cases, test fixes come with specific instructions. In general, these instructions look like the following steps. However, always use the instructions in the readme file or the instructions that are provided by IBM DevOps Deploy (Deploy) support.

Procedure

  1. Stop the server.
  2. Download the file or files for the test fix.
  3. Copy the files from the archive file to the folder app_data/patches folder, where appdata is the application data folder.
    The default application data folder is /opt/devops-deploy/server/appdata on Linux™ and C:\Program Files\devops-deploy\server\appdata on Windows™.
  4. Start the server.
  5. Log in to the server.
  6. Click Settings > Patches and verify that the test fix is installed.

What to do next

To uninstall the test fix, stop the server, remove the files from the patches folder, and restart the server.
