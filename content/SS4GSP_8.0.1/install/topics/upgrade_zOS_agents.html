Upgrading IBM z/OS agents

Edit online

You can upgrade IBM® z/OS® agents. However, you must upgrade the server before you upgrade the agents.

About this task

Depending on how the z/OS agents are installed, you have several options for upgrading the agents.

If you are upgrading to version 6.2.4 from a previous version, review IBM z/OS agent changes in version 6.2.4.

If you are upgrading to version 6.2.4 from a version earlier than 6.1.1, see Migrating data from versions before 6.1.1.

Note: IBM DevOps Deploy (Deploy) does not support upgrading z/OS agents remotely.

Procedure

  1. To upgrade from SMP/E installation, complete these steps:
    1. If a different high-level qualifier than that for the previous installation is used, edit each agent's installed.properties file, specifying the new high-level qualifier.
        • <AGENT_HOME>/conf/agent/installed.properties (file is in ASCII encoding)
        • <AGENT_HOME>/mvs/dataset.properties (file is in EBCDIC encoding)
        • <AGENT_HOME>/conf/toolkit/ISPF.conf (If using Deploy ISPF configuration)
    2. Follow the instructions in the Program Directory for Deploy for z/OS.
    3. Upgrade each agent by using one of the options in Upgrading agents
    Note:

    After the SMP/E installation, the UNIX installer is already on your file system so you can skip the first few steps in the typical command-line install or upgrade guide and start from running the shell commands. If you are following the instructions in Upgrading agents from the command line or Upgrading agents in silent mode topics, you can skip the steps that download and extract the installer. Start with running the install-agent.sh or install-agent-from-file.sh script from your SMP/E installation directory.

  2. To upgrade from a non-SMP/E installation, complete these steps:
    1. Upgrade by using one of the options in Upgrading agents.
    2. Submit a job to load the agent data sets. Locate the job JCL at agent install dir/mvs/BUZEXPD. The JCL, except the job parameter, is already customized, based on the agent configuration. Edit and submit the job to load the agent data sets. For example, use the following commands in OMVS to edit or submit the JCL: 
      oedit agent install dir/mvs/BUZEXPD
submit agent install dir/mvs/BUZEXPD
