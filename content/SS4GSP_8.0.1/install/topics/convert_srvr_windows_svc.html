Converting a server to run as a Windows service

Edit online

If you did not install the IBM DevOps Deploy (Deploy) server to run as a Windows service, you can convert the server.

Before you begin

Stop the server.

Procedure

  1. On a command line, run the following command as an administrator: 
    service.cmd install service_name

    Use the name of the service for service_name. To find the service name, open the service.cmd file in a text editor, and search for a line similar to this example: set SERVICE_NAME=devops-deploy-server.

  2. Start the server. See Starting and stopping the server.
  3. Start the Windows service.
