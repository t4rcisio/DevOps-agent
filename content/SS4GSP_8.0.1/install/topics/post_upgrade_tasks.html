Post-upgrade tasks

Edit online

After you upgrade the Deploy server, you must review all post-upgrade tasks and perform them as required.

The following table lists the tasks that you may need to perform after the server upgrade:
Task Description
Database monitoring After the upgrade, DBAs must monitor the database for at least a week to ensure optimal performance. It is important to perform the necessary database statistics actions and verify that the database is using the most efficient execution plans. For larger databases, using outdated execution plans after an upgrade can lead to significant performance issues.
Upgrade agents You must upgrade agents that use Java™ plug-ins, including most source configuration plug-ins. See Upgrading agents for information about upgrading the agents.

If you do not upgrade the agents, they will throw an IllegalCharsetNameException exception that refers to the variable DS_SYSTEM_ENCODING. See Agent throws IllegalCharsetNameException for troubleshooting the error.
Upgrade agent relays Upgrade all agent relays to the current version. Agents that connect through relays may not connect successfully until both server and relay are upgraded.
Upgrade plug-ins You may need to upgrade the plug-ins if they do not work after upgrade. See Plug-ins for information about how to install plug-ins.
Upgrade encryption key strength See Upgrading encryption key strength.
