Upgrading agent relays

Edit online

In most cases, you upgrade agents relays from the command line, but starting from 7.0.4.2 version, you can upgrade the server from the interface. Always upgrade agents and agent relays in addition to upgrading the server.

  • Upgrading agent relays remotely
    When you upgrade the server, be sure to always upgrade agents and agent relays.
  • Upgrading agent relays from the command line
    When you upgrade the server, be sure to always upgrade agents and agent relays.
  • Upgrading agent relays in silent mode
    You can upgrade agents relays by specifying the installation properties in a text file.
