Installing an agent relay in a Kubernetes cluster

Edit online

An agent relay automates application deployments through your environments. relays are especially good for coordinating environments with numerous agents. You can connect several agents outside the firewall to the server with a single relay.

Before you begin

Ensure that you complete the following prerequisite tasks:
  • Set up a working Red Hat OpenShift/Kubernetes cluster.
  • Create a project/namespace where the IBM DevOps Deploy (Deploy) agent relay will run.

For more information, refer to the README topics below.

About this task

You can install a containerized version of Deploy agent relay in an OpenShift/Kubernetes cluster. Install the Deploy agent relay by using a Helm chart or Helm based operator.

  • To install using a Helm chart, see README for Helm charts.
  • To install using an operator, see README for the case bundle.

What to do next

Set agent relay properties to control details about the installed agent relays. See, Agent relay installation properties.
