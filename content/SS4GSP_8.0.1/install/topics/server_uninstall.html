Uninstalling the server

Edit online

To uninstall the server, stop the server and then delete the main directory for the server.

Procedure

  1. Stop the server.
    See Starting and stopping the server.
  2. Delete the main directory for the server.
    The default server installation directory is /opt/devops-deploy/server on Linux™ and C:\Program Files\devops-deploy\server on Windows™.
  3. If the server was installed as a service, remove the service.
