Installing the server in an OpenShift/Kubernetes cluster

Edit online

You can install a containerized version of the IBM DevOps Deploy (Deploy) server in an OpenShift/Kubernetes cluster. The Deploy server is installed using a Helm chart or a Helm based operator.

Before you begin

Ensure that you complete the following prerequisite tasks:

  • Set up a working Red Hat OpenShift or Kubernetes cluster.
  • Create a new project/namespace where the Deploy server will run.

For more information, refer to the README topics below.

About this task

Follow the instructions to install the server in an OpenShift or Kubernetes cluster:

  • To install using a Helm chart, see README for Helm charts.
  • To install using an operator, see README for the case bundle.

What to do next

Once the Deploy server has been installed into the cluster, see Access your containerized instance to access the server URL.

    You can to access and start the IBM DevOps Deploy (Deploy) server in the Kubernetes cluster.
