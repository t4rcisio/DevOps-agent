Starting agents

Edit online

To start an agent, run the shell script or batch file.

Before you begin

Make sure that the server is running. Also, if the agent runs through an agent relay, make sure that the relay is started.

Procedure

  1. Go to the agent_installation\bin directory.
  2. Run the appropriate script:
    • To start a compact agent from console, run this command:
      ./agent.exe run
    • To start a compact agent in background, run this command:
      ./agent.exe start pidfile

      The optional pidfile argument is used for agents on UNIX™, typically when it runs from an init script.

    • On Windows™, run this command:
      agent.cmd start
    • On Linux™ or UNIX, run this command:
      ./agent start
    • On z/OS®, to run the agent as a started task, customize the sample hlq.SBUZSAMP(BUZAGNT) started task member, and then copy the task member to the SYS1.PROCLIB library. Provide the installation directory of the agent. The default installation directory of the agent is /opt/devops-deploy/agent/bin. The following lines show sample code:
      //* 
//* DevOps Deploy Agent - Start 
//*
//BUZAGNT  PROC AGENT='/opt/devops-deploy/agent/bin'
//*
//BUZAGNT  EXEC PGM=BPXBATCH,REGION=0M,TIME=NOLIMIT,
//            PARM='PGM &AGENT./agent run'
//STDOUT   DD SYSOUT=*
//STDERR   DD SYSOUT=*
//*
//        PEND
//*
      Associate the agent user ID to the started task by setting up the STARTED class profile. Enter these commands.
      SETROPTS GENERIC(STARTED)

RDEFINE STARTED BUZAGENT.*
  STDATA(USER(BUZUSR1) GROUP(BUZGRP1) TRUSTED(NO)
  DATA('DEVOPS DEPLOY AGENT')

SETROPTS CLASSACT(STARTED) RACLIST(STARTED)
 or, if the STARTED class is already in use:
SETROPTS RACLIST(STARTED) REFRESH

      To start the agent task, use the START command.
      S BUZAGNT
      To stop the agent task, use the CANCEL command. The STOP command is not supported by the Deploy z/OS agent.
      C BUZAGNT

  3. After the agent starts, go to the Deploy web application, and under Resources, open the Agents page.
