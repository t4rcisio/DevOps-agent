Installing the server database

Edit online

IBM DevOps Deploy (Deploy) requires a database. You can use the following database types for an evaluation or production server.

If you are installing an evaluation server, you can also allow the server installation program to install an Apache Derby database for you. In this case, you do not need to install a database yourself. However, you cannot use Derby for production servers. Derby is for evaluation only. To use this method, run the installation program, and when the program prompts you for the type of database, specify Derby.

Before you begin

Before you begin installing or upgrading the Deploy, ensure that you have the following permissions:
  • Data manipulation permissions. For example, insert, delete, update, and select.
  • Schema modification permissions. For example, alter a table, create a table, truncate, drop, and create or modify index.
Note: The above-mentioned user permissions required to install or upgrade Deploy can be limited based on your requirements.
  • Configuring a DB2 database
    To use a DB2® database with the server, before you install the server, install the IBM® DB2® database and provide the JDBC JAR file for the server installation process.
  • Configuring an Oracle server database
    To use an Oracle database with the server, before you install the server, install the Oracle database and provide the JDBC JAR file for the server installation process.
  • Configuring a MySQL or MariaDB database
    To use a MySQL or MariaDB database with the server, install the database first, and provide the JDBC JAR file for the server installation process.
  • Configuring a Microsoft SQL Server database
    To use an SQL Server database with the IBM DevOps Deploy (Deploy) server, install the SQL server database, install the IBM DevOps Deploy (Deploy)server, and then provide the driver file for the server installation process.
