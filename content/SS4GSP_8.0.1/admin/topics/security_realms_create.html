Creating authentication realms for the blueprint designer

Edit online

To allow users to log into the blueprint designer, you must create an authentication realm for it.

About this task

The blueprint design server supports several types of authentication realms.
Note: The authentication realms for the blueprint designer are separate from the authentication realms for the IBM DevOps Deploy (Deploy) server. However, you can import users from Deploy; see Importing user accounts from DevOps Deploy to the blueprint design server. If you import users from your Deploy server, you must import users before you connect the blueprint design server to the Deploy server.
