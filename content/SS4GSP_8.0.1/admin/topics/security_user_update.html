Updating LDAP users and groups

Edit online

LDAP users' name, addresses, and groups can be updated.

About this task

LDAP users and groups can be updated in following ways:
  • LDAP or Active Directory Authentication Realms using LDAP authorization realms to update names and email addresses.
  • SSO authentication realms using LDAP authorization realms to update groups. Names and email addresses are updated when user logs-in through SSO.
Note: You can not update users or groups if there is no LDAP Authorization realms being used.

Procedure

  1. On the server, click Settings > Authentication (Users) > select LDAP/SSO realm > Update Users for the LDAP authentication realm to use.
  2. In the Update All Users dialog box, click Submit to update the LDAP user information for the selected LDAP or SSO realm.
    The names, email addresses, and/or groups for all users in the realm are updated.
    Note: User information is also synced when a user logs-in manually from the LDAP or Active Directory.
