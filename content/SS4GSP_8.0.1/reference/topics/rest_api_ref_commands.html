REST commands for the DevOps Deploy server

Edit online

The following list shows the commands that are available for the IBM DevOps Deploy (Deploy) server.

Most of these commands have equivalent commands in the CLI. See CLI Commands.

  • agentCLI resource
    Resources for creating, editing, and deleting agents.
  • agentPool resource
  • application resource
    Resources for working with applications, including manipulating the components and environments that are associated with applications.
  • applicationPipeline resource
  • applicationProcess resource
  • applicationProcessRequest resource
    Resources for requesting application processes.
  • applicationTemplate resource
    Resources for working with application templates.
  • approval/task resource
    Resources for creating, editing, and deleting agents.
  • authenticationRealm resource
  • blueprint resource
  • calendar resource
  • component resource
  • componentProcess resource
    Resources for working with component processes.
  • componentProcessRequest resource
  • componentTemplate resource
  • deploymentTrigger resource
  • diagnostics/latency resource
  • environment resource
  • environmentTemplate resource
  • frontendServer resource
  • group resource
  • inventory resource
  • javaPackage resource
  • license resource
  • postProcessingScript resource
  • process resource
    Resources for editing and creating generic processes.
  • processRequest resource
  • relay resource
  • resource resource
  • resourceTemplate resource
    Resource for working with resource templates.
  • secretstore resource
  • serverKeystore resource
  • snapshot resource
  • sshInstallAgent resource
  • status resource
  • systemConfiguration resource
  • tags resource
    Resources for listing tags.
  • team resource
  • teamsecurity resource
  • user resource
  • vault/appRole resource
  • version resource
  • webhookTemplate resource
  • workflowTrace resource
  • zInventory resource
    Resources for manipulating Z inventory.
