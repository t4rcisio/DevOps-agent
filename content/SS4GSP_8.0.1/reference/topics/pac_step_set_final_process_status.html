set-final-process-status

Edit online

The set-final-process-status step that also appears as Set Status in the Web UI, forces the outcome status of a process to success or failure.

Format

set-final-process-status step "foo" is
    -- set workflow result to 'success' or 'failure'; required
    status success
on success
    finish
end

Properties

Table 1. Set Status property
Field Description
Status Failure or Success.

Example

start is
    start "A"
    start "B"
end

set-final-process-status step "A" is
    status success
on success
    finish
end

set-final-process-status step "B" is
    status failure
on success
    finish
end
