component-run-component-process

Edit online

The component-run-component-process step executes a component process and waits for it to complete. This step is only valid in a component process.

Format

component-run-component-process step "foo" is

    -- name of the component process to run; required
    process "deploy-my-component"

    -- set a component process property value; optional, repeatable
    property "component-process-property-1" = "cpp1-value"
    property "component-process-property-2" = "cpp1-value"
on success
    finish
end

Example

start is

    start A

    start B

end



component-run-component-process step A is

    process "proc-1"

    property "prop-1" = "prop-value-1"

    property "prop-2" = "prop-value-2"

    property "prop-3" = "prop-value-3"

on success

    finish

end



component-run-component-process step B is

    process "proc-2"

on success

    finish

end
