release-lock step

Edit online

The release-lock step releases a process lock.

Format

join step "foo" is
    finish
end

Properties

Table 1. Release lock properties
Field Description
Lock Name A string value that identifies the lock.

Example

start is
    start "A"
end

release-lock step "A" is
    lock "lock-name"
on success
    finish
end
