Process-as-code feature

Edit online

Programmatically manage processes with PAC language.

The process as code feature (PAC) lets you use the command line to create IBM DevOps Deploy (Deploy) processes. You can create scripts that define processes and then upload them to the server. You can download process designs and modify them in your text editor.

The PAC language supports Deploy processes. You write PAC scripts in the PAC language. The PAC language provides elements that describe process step commands, step properties, and connecting steps, such as Switch. PAC files are identified by the pac file extension.
