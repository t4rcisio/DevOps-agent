Java distributions

The supported software requirements to run the Deploy components (command-line client, agent, relay and server) are as follows:

Java distribution Version Notes

IBM Semeru Runtime Certified Edition 11.0.12.1 You must use a package provided by a dedicated vendor or Linux distribution with an active support contract.

Oracle Java SDK/JRE/JDK 11.0.1 and future fix packs
17 and future fix packs
21 and future fix packs
Important: You must choose a Java version above the minimum supported level for your Deploy installation. This ensures maximum flexibility for future software upgrades, letting you update Deploy and Java in separate steps rather than simultaneously. For instance, Deploy 8.0.x supports Java 11 (minimum), 17, and 21, installing Java 17 prevents a mandatory concurrent Java upgrade when moving to the next major Deploy release.
