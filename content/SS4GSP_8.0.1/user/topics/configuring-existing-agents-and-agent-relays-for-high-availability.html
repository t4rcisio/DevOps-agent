Configuring existing agents and agent relays for high-availability

Edit online

You must configure the agents and agent relays before converting them for a high-availability environment.

When migrating an existing single-server environment to a high-availability (HA) cluster, verify the connection end-points configured on all existing agents and agent relays. If the end-points do not already point to the appropriate cluster Load Balancer, Virtual IP address (VIP), or common DNS name, then update them accordingly.

For information about the properties that must be updated and their configuration requirements, see:
  • Agent installation properties
  • Agent relay installation properties
Important:
  • When configuring or updating existing agents and agent relays for an HA environment, you must follow the property-specific configuration requirements described in the agent and agent relay installation properties topics.
  • WebSocket connection properties support multiple end-points for failover.
  • The properties that are used for CodeStation HTTP artifact traffic require a single Load Balancer or VIP URL and do not support multiple URLs or failover-list syntax.
