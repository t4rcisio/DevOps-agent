Restoring a backup

Edit online

To restore a backup of the server, stop the server and replace the existing files and databases with the backup files and databases.

About this task

You can restore the server, and the app data all at once.

Restore a backup of the server as follows:

Procedure

  1. Stop the server.
  2. Copy the server files from the backup to the application data directory, overwriting the current files.
    You must restore the backup files to the same location as the existing files because configuration files include system paths.
  3. Restore the database from the backup.
    Important: You must restore the database from a backup that was taken at the same time as the backup of the application data directory.
  4. Restart the server.
