Agent metadata

Edit online

The Agent Metadata tab provides additional information about the agent.

The Agent Metadata page contains agent information categorized into the following information types:

Category Description
Java Homes Lists all Java packages installed on the agent.

Available attributes include name, vendor, version and status.
Configured Server URLs Lists all server URLs configured with the agent.

Server URLs can be used for proper assignment between the certificates and server hosts.

Configured Relay URLs Lists all relay URLs configured with the agent.
Server Public Key Pins Lists all server public keys pinned with the agent.

Server key pin information is required to remove obsolete pins, and verify that the new pins are deployed.
