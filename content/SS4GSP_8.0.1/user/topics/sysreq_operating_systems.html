Bit version support

Different parts of a product might run on the same operating system but support different application bit values.

For example, one part of the product might run only in 32-bit mode, whereas another might support 64-bit Tolerate mode.

Bit value Description
32 The product or part of the product runs as a 32-bit application on the 32-bit platforms listed as supported.
64-Tolerate The product or part of the product runs as a 32-bit application on the 64-bit platforms listed as supported.
64-Exploit The product or part of the product runs as a 64-bit application on the 64-bit platforms listed as supported.
