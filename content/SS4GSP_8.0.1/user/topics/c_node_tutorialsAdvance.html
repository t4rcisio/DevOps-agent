Advanced tutorials for experienced users.

You can find tutorials in this section that cover particular use cases, such as the Blue-Green Deployment tutorial.

Some tutorials in this section provide strategies for enterprise-scale scenarios with extensive resource requirements. Consequently, some tutorials abstractly simulate large-scale topologies. This approach means that you should be able to work through the tutorials by using a single system. Additionally, some tutorials provide a head-start by including resources that you can download or that build on other tutorials. The intermediate tutorial JPetStore tutorial, for example, is referenced by several tutorials in this section.

  • Blue-green deployments
    In this tutorial, you setup a deployment with two identical production environments, referred to arbitrarily as Blue and Green. One environment is always live, and the other environment is inactive and available to host an upgraded version.
