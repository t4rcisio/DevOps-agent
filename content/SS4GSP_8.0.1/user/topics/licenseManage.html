Licensing

Edit online

IBM DevOps Deploy (Deploy) provides a 60-day license-free evaluation period. You must have a license to use all product features after the evaluation period.

Unless you provide the location of a license server when you install Deploy, a 60-day evaluation period begins when you install the product. During the evaluation period, you can use all product features. A message on the web-based UI displays the number of days that remain in this period.

After the evaluation period, you can access Deploy to view and edit items but you cannot run deployments. You need a license for the agents in which you want to run the deployments. You can apply for a license at any point in time.

For information about setting up a IBM Common License server and applying licenses, see Getting started with IBM Common Licensing.

The IBM License Key Center is an online licensing tool. You can use this tool to generate or return your IBM product license keys.

The Deploy server is supported on z/Linux. While the licensing component is not supported on z/Linux, Deploy tracks agent usage, called agent high-water marks. You can use these records to estimate license use on your z/Linux installation. See Tracking agent usage.
Notes:
  • Relays do not require any additional licenses.
  • To minimize interruptions in access to your license server, you can configure it for high availability. See High-availability options for Rational® License Key Server.
  • Starting with Deploy v7.0.5, container bits are now part of the Entitled Registry. For more information about accessing an Entitled Registry, see Installing with the Cloud Pak for Applications command-line interface.
  • Containerized Deploy Server and agents can use the same licenses as the on-prem products. You do not need separate licenses to run the containerized products.
  • License scenarios
    After the evaluation period, you must acquire a license before you can use all product features. Several different license scenarios are available. Depending on the scenario, you might need to apply licenses to IBM DevOps Deploy (Deploy) servers, agents, or both.
  • Mixed mode licensing
    Mixed Mode Licensing gives you the ability to use both Authorized Agent licenses and Floating licenses on the same IBM DevOps Deploy (Deploy) instance for greater flexibility.
  • Applying licenses to servers and agents
    To use licenses, you install a Common Licensing server, import your license keys, and link the IBM DevOps Deploy (Deploy) servers or agents to the license server.
  • Tracking agent usage
    You can track daily agent usage. Agent usage can provide a rough estimate of agent license use.
