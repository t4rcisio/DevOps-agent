Testing an upgrade

Edit online

Before you upgrade your production IBM DevOps Deploy (Deploy) server, for best results, perform a test upgrade, verify the challenges you are facing, and resolve them before performing an actual upgrade.

The process to test an upgrade requires you to manually clone the Deploy server that includes the filesystem, database, and application data (appdata) folder to a new instance.

In this section, you create a testing environment by cloning all or most of the production environment. You test an upgrade in one of the two ways:
  • Type 1: Cloning the production server hosted on a virtual machine (VM)
  • Type 2: Cloning the production server hosted on an on-premises installation
  • Testing upgrades on a cloned virtual machine
    You can perform a test upgrade of your production server that is hosted on a virtual machine (VM).
  • Testing upgrades on a cloned on-prem installation
    You can install a new IBM DevOps Deploy (Deploy) server and then populate it with data from the production server.
