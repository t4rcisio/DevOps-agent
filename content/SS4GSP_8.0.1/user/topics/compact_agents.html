Compact agents

Edit online

Starting with V7.2.3, the agents are installed as compact agents.

A compact agent is a single-process mode for agents that enables a full upgrade of the agent software stack. It allows a Java upgrade, which was impossible without workarounds previously. In addition to this capability, compact agents also complete several other minor cleanups to the organization of the agent and its operation on Windows in particular.

Compact mode is supported on agents that run on Linux, Mac, and Windows platforms. On upgrade, the agents are switched to compact mode only on a supported platform.
