Setting up the wizard for new users

Edit online

IBM DevOps Deploy (Deploy) includes a wizard to help users become familiar with the procedures and steps in creating a deployment. Some configuration is required before the wizard can be used.

Before you begin

At least one agent must be installed and accessible to users to start and complete the introductory wizard.

About this task

The wizard is enabled with new installations of Deploy. If you are working with an upgrade, the Welcome tab that includes the push button to open the wizard must be enabled. To enable the Welcome tab, open the installed.properties file, and add this entry: server.enable.welcome.tab=true. By default, this file is in this folder: /opt/install-dir/server/conf/server.

Procedure

Tip: You don't have to create a role to assign so that they can follow the wizard. You can assign users to the Automation Engineer role, which is included on the server during installation. This Automation Engineer role has all the permissions that are required to complete the introductory wizard. If you want to create a separate role for wizard users, complete this procedure.
  1. Create a role with these permissions:
    • Create Application
    • Create Component
    • Create Environment
    • Create Resource
    • View Agent
  2. Give this role access to at least one agent.
  3. Assign this role to users so that they can start and follow the wizard.
