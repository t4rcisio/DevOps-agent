Web agent configuration

Edit online

Web agents use WebSocket and HTTPS connections for communication. Web agents do not use JMS.

Introduced with IBM DevOps Deploy (Deploy) V7.0.0, web agents are more scalable and secure than the previous agent type. The earlier type is called the JMS agent.

Web agents use the WebSocket protocol which is a bi-directional, point-to-point message protocol. WebSocket connections start as HTTPS requests and upgrade to the WebSocket protocol.

In the product user interface, web agents are recognized by the Web designation. On the Agents page, for example, web agents are the Web type.

  • Web agent communication
    For successful server and web agent communication, you must have configurations on the server and agent sides.
  • Web agent relay configuration
    Relays can be configured to support web agents exclusively.
