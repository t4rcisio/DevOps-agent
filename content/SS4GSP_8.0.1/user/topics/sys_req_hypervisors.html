Hypervisors

Edit online

You can find information about the operating system requirements for hypervisors to run IBM DevOps Deploy (Deploy).

The operating system requirements for the hypervisors to run the Deploy server are as follows:
  • AIX
  • Linux
  • Windows

AIX

The hypervisor requirements to run the Deploy server on the AIX operating system are as follows:
Hypervisor Notes
IBM PowerVM Hypervisor (LPAR, DPAR, micro-partition), all supported versions Application tier only.
Note: There are no guest operating system restrictions.

Linux

The hypervisor requirements to run the Deploy server on the Linux operating system are as follows:
Hypervisor Notes
IBM PR/SM any version Application tier only.
IBM PowerVM Hypervisor (LPAR, DPAR, micro-partition), all supported versions
KVM in SUSE Linux Enterprise Server (SLES) 12
Red Hat KVM as delivered with Red Hat Enterprise Linux (RHEL) and its Red Hat Enterprise Virtualization (RHEV) equivalent 7.0
VMware ESXi 7.0
Note: There are no guest operating system restrictions.

Windows

The hypervisor requirements to run the Deploy server on the Windows operating system are as follows:
Hypervisor Component support
KVM in SUSE Linux Enterprise Server (SLES) 12 Server
Red Hat KVM as delivered with Red Hat Enterprise Linux (RHEL) and its Red Hat Enterprise Virtualization (RHEV) equivalent 7.0 Server
VMware ESXi 7.0 Server
Note: There are no guest operating system restrictions.

For more details on system requirements, see Software product compatibility report.
