Downloading component version artifacts

Edit online

Artifacts are generated when an application process of a component version runs successfully.

About this task

You can download all artifacts of a component version or download specific artifacts of a standard type component version.

Procedure

  1. Display the component version artifacts you want to download (Components > selected component > Versions > selected version).
  2. Download artifacts using any of the following methods:
    • Click Download All to package all artifacts in one file.
    • Click Download to download a specific artifact of standard type component version.

Results

A copy of the artifacts is downloaded to your local system.
