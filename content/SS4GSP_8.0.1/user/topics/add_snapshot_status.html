Adding snapshot statuses

Edit online

Manage snapshot statuses through the snapshot options interface.

About this task

You add a status to a snapshot to provide information about the snapshot deployment status. If a snapshot deployment fails, you might apply a Failed status to them. When a snapshot is deployed, you might set the status to Active.

Procedure

  1. Click Applications > selected application.
  2. To select the snapshot, click Snapshots > selected snapshot.
  3. Click Add Status.
    The Add a status window is displayed.
  4. Select a status from the list, and click Save.

What to do next

You can now create snapshot gates using the snapshot statuses.
