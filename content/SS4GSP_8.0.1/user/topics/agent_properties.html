Setting agent properties

Edit online

Agent properties store information that are relevant to a specific agent.

About this task

Agents have many properties. These properties are categorized into:

  • Agent properties - Agent properties are uploaded by the agent during installation and are stored in the database property sheet. These properties are only updated when the agent connects with the server and by using the agent property collection APIs.
  • User-defined properties - User-defined properties are stored in VC and versioned when the properties are configured.

To view or set agent properties:

Procedure

  1. Navigate to Resources > Agents > agent name > Configuration.
  2. View the non-versioned properties from the Agent Properties table.
  3. View or update the versioned properties from the User Defined Properties table.
    You can click Add Property to add a property to the table. Each property can be deleted and edited.
