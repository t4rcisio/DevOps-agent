Managing agent relays remotely

Edit online

After an agent relay is installed, you can manage many of its features from the IBM DevOps Deploy (Deploy) web application.

About this task

Starting with Deploy version 7.0.4, you can test, restart, and delete Agent Relays directly through the user interface.

Procedure

  1. Display the Agents Relays pane (Resources > Agents Relays).
  2. Click the ... next to the relay.
    Actions are described in the following table.
    Table 1. Agent relay management
    Action Description
    Restart This option shuts down and restarts the agent relay. While the agent relay is shut down, its status is Offline.
    Test This option runs a connection test. Test results are displayed in the Connection Test dialog window.
    Delete Removes the agent relay.
