Installing a plug-in generates an error: Error loading plugin: undefined

Edit online

About this task

You attempt to install a plug-in, and you receive this message: Error loading plugin: undefined. This error message is displayed when the file system has insufficient space. The plug-in requires more space even though it seems as though enough space is available for installation.

Procedure

Depending on your hardware, add more space to the file system, and then try to install the plug-in again.

Loading a plug-in generates errors, and steps are not displayed in the process editor

Edit online

About this task

You installed a trial version of Deploy with IBM® DB2® as database. After starting the server, you cannot see any plug-ins and you are unable to load new plug-ins. Numerous errors are written to the log.

Procedure

The pagesize must be specified correctly when the DB2 database is created. Deploy DB2 requires a pagesize of 32 k. See Configuring a DB2 database.
