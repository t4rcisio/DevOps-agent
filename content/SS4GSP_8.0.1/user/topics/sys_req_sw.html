Java

Starting with the release of IBM UrbanCode Deploy v7.0.2.0, we are deprecating the JDK/JRE versions 6 and 7 for IBM UrbanCode Deploy agents. Starting February 12, 2020, JDK/JRE versions 6 or 7 on IBM UrbanCode Deploy agents are longer supported. IBM Deploy agents using Java v6 or v7 does not guarantee SSL compatibility with the IBM Deploy server using Java v8+.
